# Goblin sprites

The goblin bookkeeper stands for a planning run (routing a ticket, say), where a dragon stands for work.
Same manifest format as `../dragons/`, with the animation names meaning:

- `fly`: writing in the ledger, while the run is working.
- `roar`: waving the quill for attention, when the run needs you.
- `idle`: standing, when it is paused or has stopped.

Unlike the dragons it is drawn in its own colours and is not tinted per realm. Generated with PixelLab
(64px, side view, facing east); the writing and waving frames are on an 84px canvas, centred.
